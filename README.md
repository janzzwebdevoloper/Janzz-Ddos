# JANZZ NET-STRIKE

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python) ![Mode](https://img.shields.io/badge/Mode-Offline%20Simulation-green) ![License](https://img.shields.io/badge/License-Not%20Specified-lightgrey)

A terminal-based Python project for learning about simulated network events and cybersecurity concepts.

## Features
- Colorful terminal interface and ASCII dashboard
- Simulated network event logs
- Session history saved locally as JSON
- CSV and TXT report exports
- Event statistics and progress animations
- Adjustable display settings

## Requirements
- Python 3.10 or newer recommended
- No third-party packages required by the script

## Run
```bash
python janzzddosv4.py
```

## Safety Notice
This project is an offline simulation for educational purposes. It generates fictional events locally and does not send real network packets or perform actual denial-of-service attacks.
